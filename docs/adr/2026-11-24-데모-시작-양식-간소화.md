# 데모 시작 양식 간소화

## 상태

제안

## 맥락

/demo에 들어가면 동화보다 출시 알림 신청 양식이 먼저 뜬다.
글자 입력 칸이 여섯 개이고 버튼이 두 개("소식 받고 데모 시작", "소식 없이 데모 시작")였다.
"소식 없이"를 눌러도 이름, 성별, 나이, 알게 된 경로를 다 적어야 해서 버튼 뜻과 실제 동작이 달랐다.
태블릿(1180x820)에서는 버튼이 화면 아래로 밀려 스크롤해야 보였다.
제목도 "정식 출시 소식을 가장 먼저 받아 보세요"라 데모를 시작하는 화면인지 알기 어려웠다.
사용자 의견: 데모 시작 화면부터 사용성이 떨어진다.

## 결정

받는 정보와 서버 요청 형식은 그대로 두고 입력 방식만 바꾼다.

- 아이 나이, 성별, 알게 된 경로는 칩으로 고른다. 타이핑은 보호자 이름 한 칸뿐이다.
  - 나이: 3세 이하, 4세 ~ 7세, 8세 이상. 서버에는 예전처럼 글자("5세")로 간다.
  - 경로: 인스타그램, 지인 추천, 검색, 어린이집·유치원, 기타. 기타를 고르면 직접 적는 칸이 열린다.
- 출시 소식은 체크박스 하나로 받는다. 켜야 휴대폰 번호와 이메일 칸이 열린다.
  - 마케팅 문자 수신 동의라 기본은 꺼 둔다.
- 버튼은 "데모 시작하기" 하나다. 체크박스 상태가 wantsContact로 간다.
- 버튼은 카드 아래에 고정하고(pinActions) 본문만 스크롤한다.
- 뒤 배경은 어두운 단색 대신 첫 장면 그림을 흐리게 깐다.

정보를 건너뛰는 경로는 이번에도 만들지 않았다. 수집 항목을 줄일지는 따로 정할 일이라 건드리지 않았다.

## 영향

- 나이와 경로가 정해진 값으로 모여 집계하기 쉬워진다. 예전 자유 입력 값과는 섞여 있다.
- 소식 받기 기본값이 꺼짐이라 문자 수신 신청 비율은 예전보다 낮게 나올 수 있다.
