# 데모 화면 다듬기

## 상태

제안

## 맥락

#157에서 데모 시작 양식을 칩 선택으로 바꾼 뒤 남은 점들이다.

- 칩이 공용 FilterChip이라 보이는 높이가 30px 정도로 작았다. 태블릿에서 손가락으로 누르기에 작다.
- 질문 제목 글씨가 작고 흐려서 칩과 구분이 약했다.
- 출시 소식 체크박스가 회색 박스 안에 있어 눈에 덜 띄었다. 체크하면 칸이 위아래로 늘어 태블릿에서도 스크롤이 생겼다.
- 이야기 시작 카드의 화면 녹화 묻기가 긴 한 문단이라 무엇을 고르는지 바로 안 보였다.
- 휴대폰 세로 화면에서 읽기 중 그림이 위에 손바닥만 하게 붙고 아래 절반이 흐린 바탕뿐이었다.

## 결정

- 시작 양식 칩은 양식 안 전용 칩으로 바꾸고 보이는 높이를 44px로 한다.
- 질문 제목은 굵고 진하게 쓴다.
- 체크박스 묶음은 흰 바탕에 테두리, 켜면 보라 테두리와 옅은 보라 바탕. 넓은 카드에서는 번호와 이메일을 한 줄에 둔다.
- 화면 녹화 묻기는 "화면 녹화를 허용할까요? (선택)" 한 줄과 설명으로 나누고, 넓으면 버튼을 같은 줄 오른쪽에 둔다. 설명 뜻은 그대로다.
- 세로 화면 그림은 양옆을 한쪽 14%까지 잘라 키우고, 그림 가운데를 화면 높이 42%에 둔다. 가로 화면 규칙은 그대로다.
