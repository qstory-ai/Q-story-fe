# 품질 QA 체크리스트 (동작은 하지만 어색한 것)

노션 "QA 문서"와 같은 내용이다. 앱이 멈추거나 화면이 깨지는 기술 버그는 Linear에 올리고, 여기 항목은 노션 QA 문서의 "기록"에 남긴다.

## 점검 방법

- 기기: 태블릿 가로 화면, 소리 켜고, 「헨젤과 그레텔」 1~10화를 끝까지
- 표시: ○ 괜찮음 / △ 애매함 / ✕ 고쳐야 함
- △, ✕는 맨 아래 기록에 상세 내역을 적거나, 한 칸 더 만들어 들여쓰기로 적는다

## 1. 삽화

- [ ] 그레텔·헨젤 얼굴, 머리, 옷이 장면마다 같다
- [ ] 어른(아버지, 새어머니, 할머니/마녀)이 장면마다 같은 사람으로 보인다
- [ ] 화풍(붓 터치, 색감)이 한 동화처럼 이어진다
- [ ] 그림이 문장과 맞다 (밤/낮, 표정, 있는 물건)
- [ ] 줄거리 논리가 맞다: 숨거나 몰래 하는 장면이 숨은 모습으로, 사람 수·소품(빵 양, 가방)이 앞뒤 장면과 이어진다
- [ ] **플레이어에서** 끝까지 들으며 본다 (그림만 따로 보면 상단 버튼·자막·대화창에 가리는 걸 놓친다)
- [ ] 시도 장면에서 막힌 그림이 실패 이유와 맞다
- [ ] 얼굴과 중요한 행동이 자막·대화창에 가려지지 않는다
- [ ] 무섭거나 불편한 그림이 없다
- [ ] 흐리거나 깨진 곳, AI 티(손가락, 이상한 글자)가 없다

## 2. 내레이션·음성

- [ ] 발음이 정확하다 (이름, 받침)
- [ ] 억양이 문장 뜻과 맞다 (물음표, 슬픈 장면)
- [ ] 속도가 아이가 따라올 만하다
- [ ] 같은 인물 목소리가 계속 같다
- [ ] 녹음 음성과 실시간 음성의 차이가 크지 않다
- [ ] 소리가 끊기거나 겹치지 않고, 음량이 고르다
- [ ] 자막과 소리가 같고, 자막이 깜빡이지 않는다

## 3. 그레텔 대화

아이 역할로 이렇게 답해 보기: 정답, 준비 안 된 방법("덤불 뚫고 가자"), 한 단어("응", "몰라"), 엉뚱한 말("나 배고파"), 가만히 있기

- [ ] 아이가 한 말을 제대로 받아 준다
- [ ] 말투가 자연스러운 어린이 말이다 (번역체, 어려운 말 없음)
- [ ] 정답 쪽으로 이끌지 않는다
- [ ] 시도 장면이 "가서 → 해 보고 → 안 됐어요" 순서로 매끄럽다
- [ ] 그 자리에 없는 물건이나 장소를 쓰지 않는다
- [ ] 실패 이유가 납득되고, 아이가 주눅 들지 않는다
- [ ] 매번 같은 말("너는 ~ 같아?")로 끝나지 않는다
- [ ] 동화 설정(앞 이야기, 물건)과 어긋나지 않는다
- [ ] 엉뚱한 말이나 침묵에도 부드럽게 대처한다
- [ ] 부적절한 말에 따라가지 않는다 (안전)
- [ ] 아이를 이야기 속 인물(오빠, 헨젤)로 부르지 않는다

## 4. 말하기·음성 인식

- [ ] 아이 말을 잘 알아듣는다 (작은 목소리, 짧은 단어)
- [ ] 언제 말하면 되는지 보인다
- [ ] "음…" 하고 생각하는 사이에 녹음이 끊기지 않는다
- [ ] "도와줘" 힌트가 도움이 되고 소리로도 나온다
- [ ] 답을 기다리는 시간이 길지 않다 (10초 안쪽)
- [ ] 교실 소음이나 옆 친구 목소리에 버틴다
- [ ] 마이크 권한 안내가 쉽다

## 5. 흐름·조작

- [ ] 다음에 뭘 누를지 아이가 안다
- [ ] 버튼이 아이 손가락에 맞는 크기다
- [ ] 잘못 눌러도 돌아올 수 있다 ("다음 장면"은 한 화를 넘김)
- [ ] 장면 전환이나 로딩 중에 빈 화면이 길지 않다
- [ ] 진행 상황(몇 화인지)이 보인다
- [ ] 중간에 나갔다 와도 이어진다
- [ ] 끝나는 순간이 만족스럽다
- [ ] 수업 완료가 선생님 화면에 바로 보인다
- [ ] 글씨 크기 버튼으로 반 아이들이 읽을 만큼 키울 수 있다

## 6. 리포트·선생님 화면

- [ ] 리포트가 실제 대화와 맞다
- [ ] 대화 순서(누가 무슨 말에 어떻게 답했는지)가 보인다
- [ ] 문장이 쉽고, 내부 용어가 없다
- [ ] 아이를 비교하거나 낙인찍지 않는다
- [ ] 반 수업과 개별 수업이 구분된다
- [ ] 다음에 해 줄 것(대화 거리)이 보인다

## 7. 문구·톤

- [ ] 화면마다 말투가 같다 (해요체)
- [ ] 같은 것을 같은 이름으로 부른다
- [ ] 안내·오류 문구가 친절하고 할 일을 알려 준다
- [ ] 맞춤법, 띄어쓰기가 맞다
- [ ] 랜딩·앱·공유 문구가 같다 (슬로건 "아이의 호기심이 멈추지 않도록")
- [ ] 녹음·개인정보 안내가 보호자가 읽기 쉽다
